# /heal <player> | permission-based skript-addon
This repository contains several.sk files for a script add-on with /heal functionality.<br><br>
Important: This file is not a standalone program. The installed script plugin is absolutely required.<br>
Regardless of the age of this repository, I always recommend the _latest_ script version.<br><br>
Furthermore, the PaperMC software must be installed on the server, as this is the only officially supported server software for the script plugin.

Skript: https://github.com/SkriptLang/Skript/<br>
PaperMC: https://papermc.io/<br><br>

The script is fully customizable and includes four customizable messages.<br>

-----

| Permission | Description |
| -------- | ------- |
| ezio.skript.heal   | Main permission. If player has this permission set to true, he can heal all other players including himself. |
