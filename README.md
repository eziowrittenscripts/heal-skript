# /heal <player> | permission-based skript-addon
This repository contains several.sk files for a script add-on with /heal functionality.
Important: This file is not a standalone program. The installed script plugin is absolutely required.
Regardless of the age of this repository, I always recommend the latest script version.
Furthermore, the PaperMC software must be installed on the server, as this is the only officially supported server software for the script plugin.

Skript: https://github.com/SkriptLang/Skript/
PaperMC: https://papermc.io/
